Sign a connector config

A connector config is your organization's own app for one service, signed with your key. Upload the file on the Admin page of your PrivacyFence server, under Services.

This page runs only in your browser. It sends nothing anywhere: it has no network access, loads nothing from outside, and cannot submit a form. The key and the client secret you enter stay in this tab and are never stored. Even so, a web page is something you have to trust. If you would rather not paste your key into one, use the offline copy: the same file is in the repository and is attached to each release as privacyfence-connector-config-tool.html. Download it and open it from your disk, or use scripts/sign_connector_config.py, which does the same on the command line.
This browser cannot sign Ed25519; use scripts/sign_connector_config.py.

1. The signing key

The first connector config you upload to a server decides which key that server trusts from then on, so keep the key file safe and use the same one for every app.
