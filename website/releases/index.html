Channels

Stable is the release to install. Release candidates, betas and alphas are pre-releases for testing the next version: they get the same checks as stable, but they are newer and less proven. Install them alongside nothing you rely on. A pre-release marked superseded is older than the current stable release.

Check each installer's SHA-256 before you run it; the download page shows the command for your system. The release notes of every version, including the ones listed here, are in the changelog.
