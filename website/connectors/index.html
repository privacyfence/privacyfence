Connectors

Eleven connectors, 114 tools, each with a fixed gate.

PrivacyFence governs a defined set of connectors and the operations each one supports. It is not a generic proxy for arbitrary MCP tools. Every tool's gate is fixed in code: it runs straight away, its result is reviewed before release, or it needs your approval before anything changes.

What the assistant can read, and what it can change.

Summarized from the Tools reference, which lists every tool. Always-allow rules can let a reviewed read or a write run without a card, within the narrow scope you give them; likely personal data in a read still goes to a card.

Connecting

Your sign-in stays with PrivacyFence.

Each person connects their own account from PrivacyFence's Settings page, in the browser. The sign-in is stored by PrivacyFence and never given to the AI client. A connector's tools appear to the assistant only once it is connected.

Before that, an administrator registers an app with each provider once and packages its credentials into an organization config bundle; Telegram needs no registration. Each connector's page links its provider's setup guide, and Connecting a service the steps each person takes.
