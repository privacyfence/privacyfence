Connector · Telegram

Your Telegram chats for your AI assistant, read only after you look.

PrivacyFence connects an AI assistant to Telegram as your own account, not as a bot, so it can work with the chats, groups and channels you are in. It lists your chats straight away, reads messages only after you have reviewed them, and sends nothing until you approve.

What the assistant can do

List, read after review, send after approval.

Every Telegram tool has a gate fixed in code. The Tools reference lists each one.

Without a card

Your chat list: each chat's name, type and unread count. The call is still audited.

Reviewed before release

Recent messages in a chat, and a keyword search across your chats. You see exactly which messages would be released.

Needs your approval

Sending a message to a chat or a person. The card shows the recipient and the full text before anything is sent.

Personal data

Message text is checked before you see the card.

Before a reviewed read is shown to you, PrivacyFence scans the message text locally for likely personal data in English, German and Hungarian: IBANs, card numbers, ID and tax numbers, salary information and similar. Sender and chat names are not scanned, and email addresses and phone numbers are deliberately not flagged.

A match sends the read to a card even if an always-allow rule covers the chat, highlights what was found, and asks for a second confirmation. The audit log records the category, never the matched text.

How the PII check works

Routine requests

Trust the chats you choose.

An always-allow rule can name the chats the assistant may read, or send to, without a card. A search runs without a card only when every result comes from one of those chats. Each request is still audited, and likely personal data in a read still goes to a card. Every scope is in the scope catalogue.

Set it up

No administrator setup. Sign in with your phone.

  1. Nothing to register: every PrivacyFence installer and the PyPI package carry PrivacyFence's Telegram app credentials, which identify the application, not you.
  2. In PrivacyFence's Settings page, enter your phone number, the code Telegram sends you and, if you use one, your two-step verification password. You type them into PrivacyFence's own page, never into a terminal or the AI client.
  3. The Telegram tools appear to the assistant. You stay connected until the session expires or you end it, for example from Settings → Devices in a Telegram app.
