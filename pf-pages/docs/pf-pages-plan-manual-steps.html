pf-pages setup checklist

These are the steps only you can do for the pages plugin plan: one before implementation starts and one after the last phase merges. Ticks are saved in this browser only.

Before implementation

Create privacyfence/pf-pages and let Claude reach it

id mb1-repo-readyabout 5 minutes

Done when https://github.com/privacyfence/pf-pages/tree/plan/pf-pages shows docs/pf-pages-plan.md and .claude/toolkit.yaml. Then start a new session on pf-pages and run /devflow:implement https://github.com/privacyfence/pf-pages/blob/plan/pf-pages/docs/pf-pages-plan.md.

After implementation

Run the smoke test on a packaged PrivacyFence install

id ma1-smoke-testabout 30 minutes, plus build time

Report back as a comment on the feature PR: ma1-smoke-test: pass on <OS> <PrivacyFence version>, or fail at step <n>: <what you saw>, and tick the item in the PR description.
