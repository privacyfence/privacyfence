ma1 · Spot-check the restart line and one output read

~10 min

CI renders the enable dialog in a headless browser, but cannot check a real AI client picking up a newly enabled plugin's tools, or a real output read through it.

  1. Download the installer for your OS from the build.yml run linked in the stacked PR's description, or from the build.yml runs for feature/plugin-framework-polish (open the latest green run, then its Artifacts), and install it over your current PrivacyFence.The installer finishes and PrivacyFence starts with your plugins and connectors as before.
  2. Open Settings → Plugins and click Review again (or Review and enable) on today.The dialog ends, above Cancel and Enable, with: "After you enable it, start a new conversation in your AI client. Some clients list new tools only after they restart."
  3. Click Enable and confirm with your passkey. Then quit the Claude client completely (from the tray or menu bar), start it again and open a new conversation.today shows Running. The client's PrivacyFence tool list includes today_status.
  4. Ask the AI client for today_status.No card; the AI gets the status.
  5. Ask for today_export and approve the popup. Then ask the AI client to call plugin_outputs_read for the exported file (it can find it with plugin_outputs_list).A review card shows the CSV text. Approve it, and the AI gets the same text.
