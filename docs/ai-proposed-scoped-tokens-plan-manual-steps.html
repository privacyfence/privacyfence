Token proposal checks

Two hands-on checks for privacyfence_propose_scoped_token, done after the last phase merges into feature/ai-proposed-scoped-tokens and before that pull request merges. CI covers the logic and the page; these cover what it cannot: a real AI client, the companion's clipboard, a real passkey and a real organization bundle.

Before implementation

Nothing to do. You can run /implement straight away.

After implementation

ma1 · Local install, end to end

about 20 min

Paste into the pull request when done:

ma1 local end to end: PASS / FAIL (step number and what you saw)

ma2 · Organization test install, passkey and bundle flag

about 30 min

Use a test install and two test people, not production. Build and deploy the bundle the way docs/org-mode-setup-guide.md describes. The test person must have a passkey enrolled, and step-up must require it.

Paste into the pull request when done:

ma2 org passkey and flag: PASS / FAIL (step number and what you saw)
