1. The member rule against real Slack

about 25 min

ma1-live-member-rule. CI fakes Slack. This proves that live membership, the exclude list and member-only search work together under a scoped token in an unattended session.

You need three channel ids, from each channel's details → About panel (they start with C):

Name hereWhat it is
MEMBERA channel you are in that has no "Slack — channel" rule.
EXCLUDEDAnother channel you are in, with some message in the last hour.
OUTSIDEA public channel you are not a member of.
Paste into the pull request: 
ma1-live-member-rule: member history PASS/FAIL · outside DENIED/NOT · excluded DENIED/NOT · group DM PASS/FAIL · member_only search PASS/FAIL · plain search DENIED/NOT · audit names rule PASS/FAIL
