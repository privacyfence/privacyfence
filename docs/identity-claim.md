# The upstream identity claim (removed)

The claim-based upstream feature, which sent a signed identity claim to an upstream MCP server, was removed in 8.x.
This page is kept only so that links to it keep working. [ADR 0329](adr/0329-hosted-mcp-servers-sign-in-each-person-with-their-own-oauth-and-the-claim-feature-is-removed.md) says why it was removed, and [Upstream MCP servers](upstream-mcp.md) describes its replacement.
