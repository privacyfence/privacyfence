ma1 · Smoke-test approvals and outputs with today

~30 min

CI cannot click a real approval card that frames a plugin page and asks for a passkey, revoke the approval in Settings, or read a published output through a real AI client.

  1. Build and install today from the new branch, as an administrator, the same way as the framework smoke test: 
    git fetch origin feature/plugin-framework-cr && git checkout feature/plugin-framework-cr
python3 -m pip install -e ".[dev]"
python3 scripts/build_example_plugin.py today --out dist/plugins
    Copy dist/plugins/today over the installed folder in the plugins directory (Linux /usr/local/lib/privacyfence/plugins, macOS /Library/PrivacyFence/plugins, Windows C:\Program Files\PrivacyFence Plugins), then click Rescan in Settings → Plugins.
  2. Click Review and enable on today and enable it with your passkey.The dialog lists today_export and today_approve_layout and shows "Publishes output files: CSV".
  3. Ask the AI client to call today_approve_layout, and approve the popup card.An approval card follows. At the top, outside the framed area, it shows Plugin Today, Kind page-layout, Subject today/layout and a full sha256: digest. Below them, the framed plugin page shows the layout template. Approve it with your passkey.
  4. Open the today page (Settings → Plugins → Open page), then expand Approvals under today in Settings.The page says the layout is approved. Approvals lists one entry with kind, subject, a shortened digest and today's date.
  5. Ask for today_approve_layout again.There is no second approval card: the same digest is already approved.
  6. Click Revoke next to the approval, then reload the today page.The entry shows "Revoked <date>" and the page says not approved. Asking for today_approve_layout again shows a new card. Deny it.
  7. Ask for today_export and approve the popup. Then ask the AI client to call plugin_outputs_list for plugin today.No card for the list. It shows exports/<today>.csv with its size.
  8. Ask the AI client to call plugin_outputs_read for that file.A review card shows the CSV text in its expandable pane. Approve it, and the AI gets the same text. Ask again and pick Always allow → "this folder" (exports/). A third read shows no card.
  9. Click Export Audit Log… in Settings and open this week's file.You see plugin_approval rows ("page-layout; requested / approved / revoked / denied") and plugin_output rows ("read exports/…; offset=0; bytes=…"). No row contains the CSV content or the digest.
  10. Click Delete this plugin's data for today and confirm with your passkey.Approvals is empty, and plugin_outputs_list for today returns no files.
