ma1 · Page browser, Disable, one write result

~15 min

CI checks each piece in a headless browser and with test plugins. This checks the packaged app end to end with a real AI client.

  1. Download the installer for your OS from the build.yml run linked in the stacked PR's description, or from the build.yml runs for feature/plugin-framework-hardening (latest green run, then Artifacts), and install it over your test install.PrivacyFence starts, and today is still installed and Running.
  2. Open the Approvals page and click Plugins in the top navigation, then the page browser entry.The page browser opens in the same tab and lists today with at least one page, each with a title.
  3. Click a today page in the browser.It opens in a new tab and shows today's events (the page works, so the session went with it).
  4. In Settings → Plugins, click Disable on today.Within a few seconds the row says Disabled. Enable it again with your passkey.
  5. Quit the Claude client completely, start it again, open a new conversation and ask for today_add_note on one event. Approve the card.The AI gets a short result (the note count), not "The action ran, but its result was withheld…".
